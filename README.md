

## 📌 Project Overview

Customer Segmentation Dashboard using Machine Learning clustering techniques. This interactive Streamlit application enables users to upload customer data, perform clustering, visualize results, compare algorithms, and gain actionable business insights.

## 🛠️ Algorithms Used

- K-Means Clustering
- Hierarchical Clustering (Bonus)

## ✨ Features

- Dataset Upload
- Customer Segmentation
- Cluster Analysis
- Income & Spending Analysis
- Business Insights
- Model Comparison
